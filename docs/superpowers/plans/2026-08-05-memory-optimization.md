# 记忆系统优化实现计划

> **For agentic workers:** 使用 superpowers:subagent-driven-development 或 superpowers:executing-plans 实现，每步使用 checkbox (`- [ ]`) 跟踪。

**目标:** 修复记忆系统的四个核心问题——写入治理不统一、反序列化污染上下文、历史存储分裂、检索粗糙。

**架构:** 分两个阶段：阶段一修复可靠性（删除启发式、接通审核链路、修复反序列化），阶段二统一对话历史（PostgreSQL 唯一事实源、ManusMemoryStore 降级为适配器）。

**技术栈:** Java 21, Spring Boot 3.4, JdbcTemplate, PostgreSQL, Spring AI ChatMemory

---

## 全局约束

- 所有改动需通过 `mvn test -Dskip.frontend=true` 验证
- 删除代码优先，新增代码 minimal
- 包结构不重构，仅在现有文件内修改
- 兼容现有测试，改动后优先跑受影响测试

```java
public MemoryItem upsert(HermesCandidate candidate) {
    String memoryId = "mem-" + UUID.randomUUID().toString().substring(0, 8);
    MemoryItem item = new MemoryItem(
            null, memoryId, MemoryType.FEEDBACK,
            candidate.title(), candidate.content(),
            candidate.content(), candidate.content(),
            "Generated by Hermes from: " + candidate.sourceTraceId(),
            "Apply in future conversations",
            candidate.sourceTraceId(),
            candidate.confidence() != null ? candidate.confidence() : new BigDecimal("0.8"),
            MemoryStatus.ACTIVE, LocalDateTime.now(), null, LocalDateTime.now(),
            "hermes-applier"
    );
    memoryRepository.save(item);
    log.info("Memory upserted via Hermes: {} -> {}", candidate.candidateId(), memoryId);
    return item;
}
```

### Task 3: 修复反序列化污染

**文件:**
- 修改: `src/main/java/com/sxw/sxwaiagent/infrastructure/memory/JdbcChatMemoryRepository.java:137-166`

**改动:**

- [ ] `deserializeMessage()` 返回类型由 `Message` 改为 `Optional<Message>`
- [ ] 失败时返回 `Optional.empty()` 并记录日志+指标，不返回 `UserMessage("[deserialization error]")`
- [ ] `findByConversationId()` 对应改为 `flatMap`:

```java
@Override
public List<Message> findByConversationId(String conversationId) {
    return jdbcTemplate.query("""
            SELECT content, type, "timestamp"
            FROM ai_chat_memory
            WHERE conversation_id = ?
            ORDER BY "timestamp" ASC
            """,
            (rs, rowNum) -> {
                String contentJson = rs.getString("content");
                String typeStr = rs.getString("type");
                return deserializeMessage(typeStr, contentJson);
            },
            conversationId).stream()
            .flatMap(Optional::stream)
            .toList();
}
```

- [ ] 在 `deserializeMessage` 的 catch 块中调用一个日志方法记录坏消息 id（如有）

- [ ] 运行测试: `mvn test -Dskip.frontend=true` 确保全量通过

- [ ] Commit: `fix(chat-memory): 反序列化失败返回 Optional.empty 而非占位消息`
